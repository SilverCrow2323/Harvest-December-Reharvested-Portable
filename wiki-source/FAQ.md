# FAQ

## Is the PlayStation Vita port finished?

The repository README says the VN is still in the process of being ported. It does not describe a finished general release.

## Is there a Nintendo Switch port?

The README lists Switch as a hoped-for next target after Vita, not as a completed release.

## What is the source project?

The portable project is based on Autumn Rivers' [Harvest December: Reharvested](https://natirivers.itch.io/harvest-december-remake).

## Where can I find current updates?

The repository README points to [takoyaki99's upstream repository](https://github.com/takoyaki99/Harvest-December-Reharvested-Portable).

## Where do I install the game files?

The current README does not document a validated title-ID path or complete installation sequence. Use the instructions for the exact published release; do not copy paths from another Vita port.
