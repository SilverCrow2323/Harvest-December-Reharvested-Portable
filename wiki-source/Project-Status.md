# Project status

The project README describes a Ren'Py port of **Harvest December: Reharvested** to PlayStation Vita and Nintendo Switch.

## Current documented state

- **PlayStation Vita** is the first porting target.
- **Nintendo Switch** is a hoped-for later target.
- The project is described as still in the process of being ported.
- The code is based on Autumn Rivers' PC version of Harvest December: Reharvested.

## What this status does not claim

- It does not claim a public, finished Vita release.
- It does not claim a finished Switch build.
- It does not provide a validated install guide or compatibility matrix.
- A binary present in the repository is not, by itself, proof of a release-ready port.

## Where to follow progress

The root README points to [takoyaki99's upstream repository](https://github.com/takoyaki99/Harvest-December-Reharvested-Portable) for updates and project information.
