# Testing and reporting

Use this page to keep porting feedback reproducible. The project is still described as in progress, so reports should state exactly which build was tested.

## Record the test target

- Vita model.
- Firmware version.
- Port build or commit.
- Source/version of Harvest December: Reharvested content.
- Whether the test used the exact release instructions.

## Record the observed behavior

- Does the app boot?
- Does the main menu render?
- Can a new game start?
- Does text/audio advance correctly?
- Does the problem occur at a particular scene or action?
- Does the app exit, freeze or display a Ren'Py error?

## Report format

1. Expected result.
2. Actual result.
3. Exact steps to reproduce.
4. Build/commit and device/firmware details.
5. Redacted logs or screenshots that show the problem.

> [!WARNING]
> Do not attach original game data, proprietary assets, private saves or personal account information to a public issue.

## Where to report

Use the [portable repository issues](https://github.com/SilverCrow2323/Harvest-December-Reharvested-Portable/issues) or check the [upstream project](https://github.com/takoyaki99/Harvest-December-Reharvested-Portable) for the latest coordination.
